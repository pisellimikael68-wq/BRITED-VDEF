## Narration continue
Vous regardez vos placements et vous vous demandez si le PEA devient vraiment exonéré d'impôt ? OUI / NON. Réponse : oui, au bout de cinq ans. Règle : après cinq ans d'ancienneté du plan, les retraits échappent à l'impôt sur le revenu ; l'ancienneté court depuis la date d'ouverture du PEA. Exemple : ouvrir un PEA aujourd'hui avec dix euros le rendra mature fiscalement dans cinq ans même si vous alimentez plus tard. Nuance : les prélèvements sociaux de dix-sept virgule deux pour cent restent dus sur les gains. Vous souhaitez faire le point sur votre situation ? Prenez rendez-vous via le lien dans ma bio.

## Légende
Après cinq ans d'ancienneté du PEA (l'ancienneté commence à l'ouverture), les retraits sont exonérés d'impôt sur le revenu — seuls les prélèvements sociaux de 17,2 % restent dus. Exemple pratique : ouvrir un PEA aujourd'hui avec 10 € démarre le délai de cinq ans. Contenu pédagogique général.
