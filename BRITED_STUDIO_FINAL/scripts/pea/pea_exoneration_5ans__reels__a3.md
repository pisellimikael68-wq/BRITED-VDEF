## Narration continue
Vous ouvrez un PEA et vous pensez qu'il faut attendre d'avoir l'argent pour démarrer ? Question : l'ancienneté du PEA commence-t-elle au premier versement ou à l'ouverture - OUI / NON. Réponse : elle commence à l'ouverture du plan. Règle : après cinq ans d'ancienneté, les gains sont exonérés d'impôt sur le revenu, seuls les prélèvements sociaux de 17,2 % restent dus. Exemple : un PEA ouvert aujourd'hui avec dix euros prend date ; cinq ans plus tard, les futurs retraits seront exonérés d'impôt sur le revenu. Nuance : le capital n'est pas garanti, la valeur peut baisser. Vous souhaitez faire le point sur votre situation ? Prenez rendez-vous via le lien dans ma bio.

## Légende
Le PEA devient exonéré d'impôt sur le revenu après cinq ans d'ancienneté comptée depuis la date d'ouverture. Seuls les prélèvements sociaux de 17,2 % restent dus. Exemple concret inclus.
