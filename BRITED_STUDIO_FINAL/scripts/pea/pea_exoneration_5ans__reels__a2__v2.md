## Narration continue
Vous regardez votre PEA et vous vous demandez s'il sera imposé ? Les gains de mon PEA seront-ils imposés après cinq ans ? Après cinq ans d'ancienneté, les retraits sont exonérés d'impôt sur le revenu. Le délai de cinq ans court depuis la date d'ouverture du plan, pas depuis les versements. Exemple : ouvrir un PEA avec dix euros à vingt-cinq ans puis l'alimenter plus tard le rend mature cinq ans après l'ouverture. Attention : les prélèvements sociaux de 17,2 % restent dus sur les gains. Vous souhaitez faire le point sur votre situation ? Prenez rendez-vous via le lien dans ma bio.

## Légende
Après cinq ans d'ancienneté depuis l'ouverture, les retraits d'un Plan d'Épargne en Actions sont exonérés d'impôt sur le revenu ; seuls les prélèvements sociaux restent dus. Exemple concret inclus.
