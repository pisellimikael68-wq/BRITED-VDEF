## Narration continue
Vous avez vu « zéro impôt » pour le PEA après cinq ans ? Après cinq ans, le PEA est-il exonéré ? OUI / NON. Oui. Les retraits après cinq ans échappent à l'impôt sur le revenu. L'ancienneté se compte depuis la date d'ouverture du plan. Exemple : ouvrir un PEA aujourd'hui avec 10 € lance le compteur ; si vous alimentez ensuite, le plan est mature au bout de cinq ans. Attention : seuls les prélèvements sociaux de 17,2 % restent dus et le capital n'est pas garanti. Vous souhaitez faire le point sur votre situation ? Prenez rendez-vous via le lien dans ma bio.

## Légende
Après cinq ans d'ancienneté calculée depuis l'ouverture, les gains d'un PEA sont exonérés d'impôt sur le revenu ; seuls les prélèvements sociaux de 17,2 % restent dus. Exemple inclus.
