## Narration continue

Vous avez déjà acheté une action pour toucher son dividende ? Voulez-vous acheter avant le détachement - OUI / NON Non : le dividende n'est ni promis ni sans conséquence. Une action est une part du capital ; l'assemblée vote le dividende, qui peut être réduit, suspendu ou supprimé. Au détachement, le cours baisse du montant détaché. Exemple: distribution de 1 000 euros → le cours baisse ; le dividende est imposé au prélèvement forfaitaire unique trente pour cent sauf option pour le barème. En liquidation, les créanciers sont prioritaires : le risque de perte en capital peut être total. Vous souhaitez faire le point sur votre situation ? Prenez rendez-vous via le lien dans ma bio.
## Légende
Le dividende n'est pas un intérêt garanti : il est voté par l'assemblée et peut être réduit ou supprimé. Le détachement fait mécaniquement baisser le cours du montant détaché. Exemple chiffré et précision fiscale : PFU trente pour cent sauf option pour le barème. Contenu pédagogique général, non personnalisé.
