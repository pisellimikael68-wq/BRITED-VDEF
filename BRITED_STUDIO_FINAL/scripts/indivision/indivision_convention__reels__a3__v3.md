## Narration continue
Vous êtes héritier et redoutez qu'un cohéritier force la vente. Voulez-vous empêcher la vente ? OUI / NON. Oui, si vous concluez une convention d'indivision valable. Règle : une convention écrite et, pour un immeuble, notariée publiée suspend le droit de partage si elle est à durée déterminée. Exemple : quatre héritiers signent une convention notariée publiée pour cinq ans ; aucun indivisaire ne peut provoquer le partage pendant cette période. Attention : la convention verbale ou non publiée pour un immeuble n'est pas opposable. La durée déterminée maximale est cinq ans, renouvelable. Vous souhaitez faire le point sur votre situation ?
