## Narration continue
Vous pensez modifier votre régime matrimonial en cours de mariage ? Question : Faut‑il informer les enfants majeurs et les créanciers — OUI / NON. Réponse : Oui. Règle : Le changement se fait par acte notarié ; le notaire informe les enfants majeurs et publie pour les créanciers ; ils disposent de trois mois pour s’opposer, renvoyant l’affaire devant le juge. Exemple : Un couple signe un acte ; un enfant majeur s’oppose dans le délai de trois mois: le juge tranchera. Précision : l’homologation judiciaire reste exigée si des enfants sont mineurs. ## Légende
Information générale sur la procédure de changement de régime matrimonial : information des enfants majeurs et publicité pour les créanciers ouvrant un délai d’opposition de trois mois. Ne constitue pas un conseil personnalisé.
