## Narration continue
Selon vous, une signature chez le notaire suffit-elle pour changer de régime matrimonial ? Non. L’acte notarié est indispensable, mais d’autres étapes peuvent être nécessaires. Les enfants majeurs et les créanciers sont informés, car le changement peut modifier les biens sur lesquels ils peuvent être payés. Tous disposent de trois mois pour s’opposer. En cas d’opposition, le tribunal doit homologuer l’acte. Pour un mineur, le notaire peut saisir le juge si ses intérêts risquent d’être compromis. Si elle est nécessaire, la liquidation de l’ancien régime figure dans l’acte : elle établit les patrimoines et les comptes entre époux. Exemple : un entrepreneur choisit la séparation de biens pour mieux isoler son conjoint du risque professionnel. Le bon régime dépend de votre famille, de vos biens et de vos objectifs. Étudiez toutes ses conséquences avant de signer. Vous souhaitez faire le point sur votre situation ? Prenez rendez-vous via le lien sur mon profil.

## Légende
L’article 1397 du Code civil organise le changement de régime matrimonial : acte notarié, information des enfants majeurs et des créanciers, délai d’opposition, homologation en cas d’opposition et protection possible d’un enfant mineur.
