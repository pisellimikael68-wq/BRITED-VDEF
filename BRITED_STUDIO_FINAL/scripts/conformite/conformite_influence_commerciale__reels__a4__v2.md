## Narration continue
Vous regardez une vidéo où quelqu'un dit «Faites cet investissement». Ai‑je le droit de recommander un placement personnellement ?  OUI  |  NON Non, donner une recommandation personnalisée suppose un statut réglementé. Expliquer un mécanisme financier est libre ; conseiller une personne demande le statut de conseiller en investissement financier. Dire «ce fonds est idéal pour vous» est une recommandation nécessitant un statut ; expliquer comment fonctionne un fonds reste possible sans statut. La responsabilité pèse sur le créateur même si l'annonceur fournit le message. Vous souhaitez faire le point sur votre situation ? Prenez rendez-vous via le lien dans ma bio.

## Légende
La recommandation personnalisée d'un placement exige un statut réglementé. Expliquer un mécanisme reste libre ; conseiller une personne nécessite le statut de conseiller en investissement financier. La responsabilité pèse sur le créateur même si le message vient de l'annonceur. Vous souhaitez faire le point sur votre situation ? Prenez rendez-vous via le lien dans ma bio.
