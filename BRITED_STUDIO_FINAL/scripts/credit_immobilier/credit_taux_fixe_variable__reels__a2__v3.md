## Narration continue
Offre de prêt : taux fixe, variable ou mixte, vous hésitez ? Faut-il choisir selon une prévision des taux ? [OUI] [NON] Non, le choix porte sur qui supporte le risque de taux. Taux fixe : mensualité et coût connus pour toute la durée ; taux variable : suit un indice et transfère le risque. Un taux variable n'est acceptable que s'il est assorti d'un plafond. Exemple : mixte = fixe quelques années puis variable, adapté si vous avez une épargne de sécurité. Attention : la variation peut porter sur la mensualité ou sur la durée, ce qui change le coût. Vous souhaitez faire le point sur votre situation ? Prenez rendez-vous via le lien dans ma bio.

## Légende
Le choix entre taux fixe, variable ou mixte n'est pas une prévision des taux mais une décision sur qui supporte le risque. Un taux variable doit être assorti d'un plafond. Vérifiez si l'ajustement porte sur la mensualité ou sur la durée. Contenu pédagogique général.
