## Narration continue

Taux fixe, variable ou mixte : qui supporte le risque ? Le choix définit qui porte le risque de hausse. Taux fixe : taux et mensualité figés, la banque porte le risque. Taux variable : indexé sur un indice, souvent proposé initialement plus bas, mais l'emprunteur supporte les hausses ; il doit être capé. Capé '+1' = taux maximum = taux initial + 1 point. Mixte : fixe puis variable. Exemple : fixe 900 euros vs variable 850 euros puis risque d'augmentation. Comparez le taux annuel effectif global et vérifiez le statut de l'assurance emprunteur.
