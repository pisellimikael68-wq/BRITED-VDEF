## Narration continue
Taux fixe, variable ou mixte : lequel choisir pour votre crédit immobilier ? Le choix porte sur qui supporte le risque de hausse des taux, pas sur une prédiction. Taux fixe : le taux et la mensualité sont figés sur toute la durée. Taux variable : indexé sur un indice, révisé périodiquement ; acceptable seulement s'il existe un plafond de variation. Mixte : période initiale fixe puis bascule en variable. Exemple : un capé '+1' signifie que le taux ne peut dépasser le taux initial augmenté d'un point. Attention : certains contrats ajustent la durée plutôt que la mensualité, ce qui peut prolonger fortement le prêt. Vous souhaitez faire le point sur votre situation ?
