## Narration continue
Taux fixe, variable ou mixte : qui supporte le risque de taux ? Le choix porte sur qui prend le risque, pas sur prévoir les taux. Taux fixe = mensualité et coût connus, banque supporte le risque. Taux variable = indexé sur un indice, mensualité ou durée révisable; il doit être capé sinon risque illimité. Mixte = période initiale fixe puis variable. Exemple : prêt 20 ans, fixe ou variable capé +1. Un capé +1 signifie que le taux ne peut dépasser le taux initial augmenté d'un point. Attention : certains contrats font varier la durée, pas la mensualité ; cela protège le budget mais augmente le coût total. Vous souhaitez faire le point sur votre situation ?
