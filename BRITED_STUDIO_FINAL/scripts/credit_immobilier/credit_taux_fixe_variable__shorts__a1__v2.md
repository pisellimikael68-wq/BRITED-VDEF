## Narration continue
Taux fixe, variable ou mixte : lequel choisir pour un crédit immobilier ? Le choix porte sur qui supporte le risque de taux, pas sur savoir comment évolueront les marchés. Taux fixe : mensualité et coût total connus pendant toute la durée, la banque porte le risque. Taux variable : indexé sur un indice de référence et révisé périodiquement ; acceptable seulement s’il est assorti d’un plafond de variation. Le seul chiffre comparable est le taux annuel effectif global. Exemple : un crédit mixte peut appliquer un taux fixe pendant cinq ans puis basculer en variable. Un « capé +1 » ne peut dépasser le taux initial augmenté d’un point. Attention : selon le contrat la variation peut jouer sur la durée plutôt que sur la mensualité. Abonnez‑vous pour d’autres explications ; cette vidéo est d’information générale.
