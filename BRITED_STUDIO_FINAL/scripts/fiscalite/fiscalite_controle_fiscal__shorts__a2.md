## Narration continue
Contrôle fiscal : combien de temps l'administration peut-elle revenir ? Trois ans pour l'impôt sur le revenu, six ans si une succession n'a pas été déclarée, dix ans pour avoirs à l'étranger non déclarés. Le délai expire le 31 décembre de la troisième année suivant l'imposition pour l'impôt sur le revenu ; les droits d'enregistrement sont trois ans, six ans s'il n'y a pas de déclaration ; les comptes étrangers non déclarés dix ans. Exemple : un revenu de 2023 contrôlable jusqu'au 31 décembre 2026 ; héritage non déclaré contrôlable six ans ; un compte étranger non déclaré contrôlable dix ans. Attention : le défaut de déclaration ou la fraude allongent les délais ; une erreur de bonne foi ne les prolonge pas. Vous souhaitez faire le point sur votre situation ? Prenez rendez-vous via le lien dans ma bio.
