## Narration continue

Micro-foncier ou réel : quel seuil change tout ? Si vos charges réelles dépassent trente pour cent des loyers, le régime réel peut être plus avantageux. Le micro-foncier s'applique si les revenus fonciers bruts du foyer n'excèdent pas quinze mille euros et offre un abattement forfaitaire de trente pour cent ; le réel déduit les charges listées à l'article 31 du Code général des impôts. Exemple : loyers douze mille euros, charges cinq mille euros — 41,7 % ; le réel déduit ces charges ; si cela crée un déficit hors intérêts, il s'impute sur le revenu global dans la limite de dix mille sept cents euros par an. Attention : la part du déficit provenant des intérêts d'emprunt ne s'impute que sur les revenus fonciers et l'option pour le réel engage trois ans. Vous souhaitez faire le point sur votre situation ?
