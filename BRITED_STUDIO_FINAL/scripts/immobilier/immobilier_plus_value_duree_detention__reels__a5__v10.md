## Narration continue

Vous vendez un appartement loué après vingt-deux ans : est-ce exonéré ? OUI / NON. Non. La plus-value est taxée à trente-six virgule deux pour cent. Pour l'impôt, abattement dès la sixième année : six pour cent par an jusqu'à vingt-et-un ans puis quatre pour cent la vingt-deuxième — l'impôt disparaît à vingt-deux ans. Pour les prélèvements sociaux, abattement un virgule soixante-cinq pour cent par an puis neuf pour cent après vingt-et-un ans — exonération à trente ans. Exemple : à vingt-deux ans l'impôt de dix-neuf pour cent est effacé, mais les prélèvements sociaux restent dus. Conservez vos factures de travaux : elles augmentent le prix d'achat et réduisent la base taxable. Vous souhaitez faire le point sur votre situation ? Prenez rendez-vous via le lien dans ma bio.
## Légende
Vendre un bien locatif après 22 ans efface l'impôt sur la plus-value, mais les prélèvements sociaux restent calculés différemment et ne s'effacent qu'à 30 ans. Conservez les factures de travaux pour réduire la base taxable. Contenu pédagogique général.
