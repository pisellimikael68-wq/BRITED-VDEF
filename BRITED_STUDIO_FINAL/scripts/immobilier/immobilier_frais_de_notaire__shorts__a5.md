## Narration continue
Les frais de notaire : vont ils vraiment au notaire ? Non — presque pas. Les « frais de notaire » désignent les frais d'acquisition : droits de mutation, débours, émoluments. Dans l'ancien 7 à 8 % ; la rémunération du notaire ≈ 1 %. Dans le neuf 2 à 3 %. Exemple : pour 300 000 euros dans l'ancien, frais ≈ 22 000 euros et le notaire garde ≈ 3 000 euros ; pour le neuf les frais ≈ 7 500 euros sur le même prix. Attention : les frais se calculent sur le prix hors mobilier — la valeur du mobilier peut être exclue si elle est justifiée par facture. Vous souhaitez faire le point sur votre situation ?
