## Narration continue
Vous avez un livret sans plafond et vous vous demandez s'il est avantageux ? OUI / NON Non. Les intérêts du compte sur livret sont imposés. Ils supportent le prélèvement forfaitaire unique de trente pour cent sauf option pour le barème. La règle : pas de plafond, taux libre fixé par la banque, mais fiscalité s'applique toujours. Exemple : un taux brut de trois pour cent rapporte deux virgule un pour cent après la retenue de trente pour cent. Réserve : les taux promotionnels peuvent être limités dans le temps ou au montant, ce qui réduit le rendement annuel. Vous souhaitez faire le point sur votre situation ? Prenez rendez-vous via le lien dans ma bio.

## Légende
Le compte sur livret est un produit d'épargne sans plafond mais soumis au prélèvement forfaitaire unique de 30 % sur les intérêts, sauf option pour le barème. Exemple chiffré : 3 % brut → 2,1 % net après PFU. Source officielle en bas.
