## Narration continue
Faut‑il remplir le formulaire 2086 pour vos cessions de crypto‑actifs ? Oui, quand vous cédez contre une monnaie ayant cours légal ou pour acheter un bien. Le 2086 exige un calcul cession par cession : prix de cession rapporté à la valeur globale du portefeuille à l'opération, diminué du prix d'acquisition proportionnel ; chaque cession est détaillée ligne par ligne. Exemple : vous cédez 500 euros et recevez 520 euros ; la plus‑value de cette cession est calculée et reportée sur la 2042 C via l'annexe 2086. Attention : le seuil de 305 euros porte sur le montant total des cessions annuelles, pas sur le gain ; sans historique d'acquisition, la base peut être nulle. Vous souhaitez faire le point ?
