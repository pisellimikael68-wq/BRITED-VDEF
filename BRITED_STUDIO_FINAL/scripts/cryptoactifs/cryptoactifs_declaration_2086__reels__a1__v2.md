## Narration continue
Vous avez vendu des cryptos et vous vous demandez si vous devez les déclarer ? OUI ou NON ? Oui si vous avez cédé contre une monnaie ayant cours légal. Non pour les simples échanges entre cryptoactifs. Chaque cession contre une monnaie ayant cours légal se déclare cession par cession sur le formulaire 2086. Exemple : ventes totalisant 2 000 euros dans l'année, même pour un gain de quarante euros, dépassent le seuil de 305 euros et doivent être déclarées. Attention : les comptes d'actifs numériques ouverts à l'étranger se déclarent séparément ; l'omission entraîne une amende par compte. Vous souhaitez faire le point sur votre situation ? Prenez rendez-vous via le lien dans ma bio.

## Légende
Chaque cession convertie en euro ou monnaie ayant cours légal doit être détaillée ligne par ligne sur le formulaire 2086. Seuil annuel de 305 euros porte sur le montant total des cessions. Déclaration séparée pour les comptes ouverts à l'étranger : omission sanctionnée par une amende par compte.
