## Narration continue
Vous regardez votre relevé et vous ne voyez aucune ligne 'frais' pour votre fonds — c'est normal. Question affichée : les frais d'un fonds apparaissent-ils sur mon relevé ? OUI | NON. Non. Les frais de gestion sont déduits quotidiennement de la valeur liquidative : la valeur publiée est déjà nette. Règle : ils ne figurent sur aucun relevé mais sont indiqués dans le document d'informations clés. Exemple : un fonds prélève ses frais chaque jour, vous voyez seulement une VL plus faible, pas une ligne débit. Nuance : le contrat hôte ajoute ses propres frais qui s'additionnent. Vous souhaitez faire le point sur votre situation ? Prenez rendez-vous via le lien dans ma bio.

## Légende
Les frais de gestion d'un fonds sont prélevés directement sur la valeur liquidative et n'apparaissent pas sur votre relevé. Le document d'informations clés (DIC) indique les frais obligatoires. Le contrat qui abrite le fonds peut ajouter d'autres frais.
