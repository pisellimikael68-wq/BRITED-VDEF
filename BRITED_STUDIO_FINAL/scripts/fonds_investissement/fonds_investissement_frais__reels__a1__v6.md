## Narration continue

Vous feuilletez votre relevé et vous ne voyez aucune ligne "frais" — ça vous est déjà arrivé ? Est-ce que les frais de votre fonds apparaissent sur le relevé ? OUI ☐   NON ☐ Non. Ils n'apparaissent pas sur le relevé. Ils sont prélevés quotidiennement sur la valeur liquidative : la valeur publiée est déjà nette de frais. Exemple : la valeur d'une part diminue chaque jour parce que les frais sont déduits en continu ; le document d'informations clés indique le taux annuel. Attention : les frais du contrat qui abrite le fonds s'ajoutent et doivent être additionnés séparément. Vous souhaitez faire le point sur votre situation ? Prenez rendez-vous via le lien dans ma bio.
## Légende
Les frais de gestion d'un fonds sont prélevés quotidiennement sur la valeur liquidative et n'apparaissent pas sur votre relevé ; consultez le document d'informations clés pour connaître le taux annuel.
