## Narration continue
Vous feuilletez votre relevé et vous ne trouvez aucune ligne 'frais' ? Les frais d'un fonds apparaissent-ils sur votre relevé ? OUI / NON Non. Les frais des placements collectifs sont retirés en continu de l'actif : la valeur liquidative publiée est déjà nette de frais. Règle clé : les frais sont indiqués dans le document d'informations clés, pas sur le relevé. Exemple : un fonds publie chaque jour une valeur liquidative diminuée des frais, donc la performance affichée a déjà intégré ce prélèvement. Nuance : les frais du contrat qui héberge le fonds s'ajoutent à ceux du fonds. Vous souhaitez faire le point sur votre situation ? Prenez rendez-vous via le lien dans ma bio.
