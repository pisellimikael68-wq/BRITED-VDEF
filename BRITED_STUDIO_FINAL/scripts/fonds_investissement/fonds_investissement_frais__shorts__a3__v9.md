## Narration continue

Les frais d'un fonds se voient-ils sur votre relevé ? Non. Ils ne figurent pas en ligne : ils sont prélevés sur l'actif et réduisent la valeur liquidative publiée. Cela signifie que la valeur de la part est nette de ces frais ; le document d'informations clés indique le pourcentage annuel. Exemple : si un fonds affiche 1,5 % de frais annuels, ils sont prélevés sur la valeur et grignotent la performance cumulée sur trente ans. Nuance : le fonds supporte ses frais, mais le contrat d'assurance-vie ou un mandat peuvent ajouter d'autres pourcentages — additionnez % du fonds + % du contrat + % du mandat pour estimer le coût total. Vous souhaitez faire le point sur votre situation ? Prenez rendez-vous via le lien dans ma bio.
