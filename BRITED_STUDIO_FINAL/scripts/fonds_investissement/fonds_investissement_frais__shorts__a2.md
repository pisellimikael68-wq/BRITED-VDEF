## Narration continue
Les frais de votre fonds apparaissent-ils sur votre relevé ? Non, ils sont déjà prélevés sur la valeur liquidative. Les frais de gestion sont déduits quotidiennement de la valeur liquidative; ils n'apparaissent donc sur aucune ligne de relevé. Par ordre de grandeur, un surcoût de 1,5 pour cent par an, sur trente ans, peut représenter plus d'un tiers du capital final. Attention, le fonds peut être logé dans un contrat qui ajoute ses propres frais; il faut additionner les niveaux de frais. Le document d'informations clés indique les frais; consultez-le. Source : AMF et Code monétaire et financier. Vous souhaitez faire le point sur votre situation ? Prenez rendez-vous via le lien dans ma bio.
