## Narration continue

Vous consultez votre relevé, vous payez. Votre relevé montre-t-il les frais de gestion du fonds ? [ OUI ]   [ NON ] Non, ils n'apparaissent pas sur votre relevé. Les frais sont déduits quotidiennement de la valeur liquidative : la valeur publiée est déjà nette de frais. Par exemple, des frais annuels de 1,5 % réduisent l'accumulation ; sur trente ans cela représente plus d'un tiers du capital final. Attention : s'ajoutent aussi les frais du contrat qui héberge le fonds et d'un mandat ; le total n'apparaît sur aucun document unique. Vous souhaitez faire le point sur votre situation ? Prenez rendez-vous via le lien dans ma bio.
## Légende
Les frais de gestion d'un fonds sont déduits quotidiennement de la valeur liquidative, donc invisibles sur les relevés. Consultez le document d'informations clés pour connaître les frais du fonds et ajoutez les frais du contrat qui l'héberge pour estimer le coût total.
