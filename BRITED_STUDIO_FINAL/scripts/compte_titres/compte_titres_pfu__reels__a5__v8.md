## Narration continue

30 % prélevés sur dividendes ou plus-values ? Dois-je cocher la case pour le barème ? OUI / NON Pas forcément : le barème peut être moins coûteux en tranches basses. Par défaut le PFU taxe ces revenus à 30 % : 12,8 % d'impôt et 17,2 % de prélèvements sociaux. Exemple : un foyer en tranche 0 % ou 11 % paie 12,8 % avec le PFU, alors que le barème coûterait 0 % ou 11 % ; les dividendes bénéficient d'un abattement de 40 % au barème. Attention : l'option pour le barème est globale et annuelle sur l'ensemble des revenus du capital du foyer. Vous souhaitez faire le point sur votre situation ?
