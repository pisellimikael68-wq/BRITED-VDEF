## Narration continue

30 % prélevés sur vos dividendes ? Dois-je cocher la case pour le barème ? OUI / NON Non obligatoire : l'option pour le barème peut coûter moins en tranches basses. Par défaut le PFU taxe ces revenus à 30 % : 12,8 % d'impôt et 17,2 % de prélèvements sociaux. Exemple : foyer en tranche 0 % ou 11 % — PFU 12,8 % vs barème 0 % ou 11 % ; dividendes : abattement 40 % si option. Attention : l'option est globale et annuelle pour les revenus du capital du foyer.
