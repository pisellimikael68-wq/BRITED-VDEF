## Narration continue
Vous avez vu 30 % prélevés ? Question : Choisir la flat tax ou le barème progressif - OUI / NON. Réponse : Le barème peut l'être. Règle : Par défaut le PFU est à 30 % soit 12,8 % d'impôt et 17,2 % de prélèvements sociaux ; si votre tranche marginale est 0 % ou 11 % le barème peut coûter moins, avec un abattement de 40 % sur dividendes. Exemple : Foyer en tranche 11 % paie 12,8 % avec PFU ; le barème avec abattement réduit l'impôt. Nuance : L'option est globale et annuelle pour le foyer.
