## Narration continue

La banque a prélevé 30 % sur votre gain ? Dois-je cocher la case pour le barème ? OUI / NON Pas forcément — selon votre tranche, le barème peut coûter moins. PFU = 30 % : 12,8 % impôt + 17,2 % prélèvements sociaux. Exemple : sur 1 000 €, PFU = 300 € ; en tranche 11 % impôt 110 € + sociaux 172 € → total 282 €. Si vous optez pour le barème, la part d'impôt bascule ; les prélèvements sociaux 17,2 % restent dus. L'option est globale, annuelle et irrévocable pour l'année. Vous souhaitez faire le point sur votre situation ? Prenez rendez-vous via le lien dans ma bio.
