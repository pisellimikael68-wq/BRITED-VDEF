## Narration continue

30 % prélevés sur dividendes ? Dois-je cocher la case pour le barème ? OUI/NON Non obligatoire : le barème peut coûter moins en tranches basses. Par défaut le PFU taxe ces revenus à 30 % : 12,8 % impôt et 17,2 % prélèvements sociaux. Exemple : un foyer en tranche 0 % ou 11 % paie 12,8 % ; barème reviendrait à 0 % ou 11 % ; dividendes : abattement 40 %. Attention : l'option est globale et annuelle sur les revenus du capital du foyer. Vous souhaitez faire le point sur votre situation ? Prenez rendez-vous via le lien dans ma bio.
