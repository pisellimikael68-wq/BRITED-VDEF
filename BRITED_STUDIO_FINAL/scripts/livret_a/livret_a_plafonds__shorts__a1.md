## Narration continue
Combien puis-je mettre sur un Livret A ? Vous pouvez verser jusqu'au plafond en versements cumulés, mais le solde n'est pas figé. La règle : le plafond de vingt-deux mille neuf cent cinquante euros pour le Livret A et douze mille euros pour le LDDS porte sur les versements cumulés uniquement — les intérêts capitalisés peuvent donc faire dépasser le solde. Exemple : si vous versez vingt-deux mille neuf cent cinquante euros, le livret continue de produire des intérêts qui s'ajoutent au capital ; le solde peut atteindre vingt-trois mille euros. Nuance : une seule personne ne peut détenir qu'un seul Livret A ; la détention multiple est interdite et sanctionnée. Vous souhaitez faire le point sur votre situation ?
