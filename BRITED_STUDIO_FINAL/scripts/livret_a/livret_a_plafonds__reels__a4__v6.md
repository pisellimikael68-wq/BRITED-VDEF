## Narration continue

Vous regardez votre relevé et votre Livret A dépasse le plafond affiché ? Peut-on encore y verser ? [ OUI ] [ NON ] Oui. Le plafond concerne les versements cumulés, pas le solde : les intérêts capitalisés continuent de s'ajouter et peuvent porter le solde au‑delà de 22 950 euros. Par exemple, si vous avez versé 22 950 euros, les intérêts suivants font monter le solde sans nouveau versement. Attention : une seule ouverture par personne, la détention multiple est interdite et sanctionnée. Le LEP peut être plus rémunérateur si vous êtes éligible. Vous souhaitez faire le point sur votre situation ? Prenez rendez-vous via le lien dans ma bio.
## Légende
Le plafond du Livret A et du LDDS porte sur les versements cumulés, pas sur le solde : les intérêts capitalisés peuvent porter le solde au‑delà du plafond. Exemple chiffré : plafond Livret A 22 950 euros. Une seule ouverture par personne ; la détention multiple est interdite et sanctionnée. Le LEP peut être plus rémunérateur pour les foyers éligibles.
