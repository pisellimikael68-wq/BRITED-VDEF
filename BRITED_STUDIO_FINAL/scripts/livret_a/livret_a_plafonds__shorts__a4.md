## Narration continue
Combien puis‑je mettre sur un Livret A ? Réponse immédiate : le plafond concerne les versements cumulés, pas le solde. Règle : le Livret A et le LDDS sont exonérés d'impôt et disponibles à tout moment ; leurs plafonds (Livret A vingt-deux mille neuf cent cinquante euros, LDDS douze mille euros) limitent les dépôts cumulés mais pas les intérêts, qui capitalisés peuvent porter le solde au‑dessus du plafond. Exemple : si vous versez 22 950 euros puis recevez des intérêts, votre solde peut dépasser 22 950 euros sans violation. Nuance : une seule personne ne peut détenir plusieurs Livret A ; et le LEP peut être mieux rémunéré pour les foyers éligibles. Vous souhaitez faire le point sur votre situation ? Prenez rendez-vous via le lien dans ma bio.

## Légende
Les livrets réglementés ont des plafonds sur les versements cumulés, pas sur le solde : les intérêts capitalisés peuvent porter le solde au‑dessus du plafond. Un seul Livret A par personne ; vérifiez votre éligibilité au LEP si vos revenus le permettent.
