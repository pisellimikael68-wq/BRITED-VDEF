## Narration continue
Vous regardez votre relevé et voyez le Livret A au-dessus du plafond ? Peut-on encore verser dessus ? OUI / NON. Oui. Le plafond concerne les versements cumulés et non le solde : les intérêts capitalisés continuent de s'ajouter et peuvent faire dépasser le solde. Exemple : si vos versements atteignent 22 950 euros, les intérêts suivants augmentent le solde au‑delà de cette somme. Précision importante : une seule ouverture de Livret A par personne, la détention multiple est interdite et sanctionnée. Le LEP peut être une meilleure option pour les foyers éligibles. Vous souhaitez faire le point sur votre situation ? Prenez rendez-vous via le lien dans ma bio.

## Légende
Le plafond du Livret A limite les versements cumulés, pas le solde : les intérêts peuvent porter le solde au‑delà de 22 950 €. Une seule ouverture par personne ; la détention multiple est interdite et sanctionnée. Vérifiez l'éligibilité au LEP si vos revenus le permettent.
