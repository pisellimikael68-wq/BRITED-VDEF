## Narration continue
Vous pouvez dépasser le plafond du Livret A avec les intérêts. Le Livret A et le LDDS ont un plafond sur les versements cumulés, pas sur le solde. Vous pouvez donc continuer à gagner des intérêts quand vos dépôts atteignent vingt-deux mille neuf cent cinquante euros pour le Livret A ou douze mille euros pour le LDDS : ces intérêts s’ajoutent au capital et peuvent porter le solde au-delà du plafond. Exemple : versez vingt-deux mille neuf cent cinquante euros ; les intérêts porteront le solde au-dessus du plafond sans nouveau versement. Attention : un seul Livret A par personne et le LEP peut être mieux rémunéré selon le revenu fiscal. Vous souhaitez faire le point sur votre situation ? Prenez rendez-vous via le lien dans ma bio.

Vidéo pédagogique : explication claire que le plafond concerne les versements cumulés et non le solde ; exemple chiffré ; réserve sur détention et alternatives.
