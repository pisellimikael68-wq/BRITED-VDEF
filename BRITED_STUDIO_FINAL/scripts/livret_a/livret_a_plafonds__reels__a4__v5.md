## Narration continue
Vous consultez votre relevé et votre Livret A dépasse le plafond ? Peut-on encore y verser ? [ OUI ] [ NON ]. Oui. Le plafond s'applique aux versements cumulés, pas au solde : les intérêts capitalisés continuent de s'ajouter et peuvent porter le solde au-delà de 22 950 euros. Par exemple, si vos versements atteignent 22 950 euros, les intérêts suivants augmentent le solde au-delà sans nouveau versement. À noter : une seule ouverture par personne, la détention multiple est interdite et sanctionnée. Le LEP peut offrir une rémunération supérieure pour les foyers éligibles. Vous souhaitez faire le point sur votre situation ? Prenez rendez-vous via le lien dans ma bio.

## Légende
Le plafond du Livret A et du LDDS porte sur les versements cumulés, pas sur le solde : les intérêts capitalisés peuvent porter le solde au‑delà du plafond. Exemple chiffré : plafond Livret A 22 950 euros. Une seule ouverture par personne ; la détention multiple est interdite et sanctionnée. Le LEP peut être plus rémunérateur pour les foyers éligibles.
