## Narration continue
Vous voyez votre Livret A dépasser le plafond sur votre relevé ? Peut-on encore verser dessus ? OUI / NON. Oui. Le plafond concerne les versements cumulés, pas le solde : les intérêts capitalisés continuent de s'ajouter et peuvent porter le solde au‑delà. Exemple : si vos versements atteignent 22 950 euros, les intérêts suivants peuvent faire dépasser le solde. Attention : un seul Livret A par personne, la détention multiple est interdite et sanctionnée. Le LEP peut mieux rémunérer les foyers éligibles. Vous souhaitez faire le point sur votre situation ? Prenez rendez-vous via le lien dans ma bio.

## Légende
Le plafond du Livret A et du LDDS porte sur les versements cumulés, pas sur le solde : les intérêts capitalisés peuvent porter le solde au‑delà du plafond. Exemple chiffré : plafond Livret A 22 950 euros. Une seule ouverture par personne ; la détention multiple est interdite et sanctionnée. Le LEP peut être plus rémunérateur pour les foyers éligibles.
