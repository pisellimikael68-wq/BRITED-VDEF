## Narration continue
Vous voyez votre Livret A dépasser le plafond sur le relevé ? Peut-on encore verser dessus ? OUI / NON. Oui. Le plafond porte sur les versements cumulés, pas sur le solde : les intérêts capitalisés peuvent faire dépasser le solde. Exemple : si vos versements cumulés atteignent 22 950 euros, les intérêts continuent de s'ajouter et le solde peut dépasser ce plafond. Rappel : un seul Livret A par personne, la détention multiple est interdite et sanctionnée. Le LEP reste une option pour foyers éligibles. Vous souhaitez faire le point sur votre situation ? Prenez rendez-vous via le lien dans ma bio.

## Légende
Le plafond du Livret A limite les versements cumulés, pas le solde : les intérêts peuvent porter le montant au-delà des 22 950 €. Un seul Livret A par personne ; vérifiez l'éligibilité au LEP si vos revenus le permettent. Sources : Code monétaire et financier et Service-public.fr.
