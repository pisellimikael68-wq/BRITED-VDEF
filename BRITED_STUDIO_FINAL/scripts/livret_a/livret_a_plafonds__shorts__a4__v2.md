## Narration continue
Combien puis-je mettre sur un Livret A ? Le plafond porte sur les versements cumulés, pas sur le solde. Le Livret A et le LDDS sont exonérés d'impôt et disponibles à tout moment ; leurs plafonds — Livret A 22 950 euros, LDDS 12 000 euros — limitent les dépôts cumulés mais pas les intérêts, qui capitalisés peuvent porter le solde au‑dessus du plafond. Exemple : vous versez 22 950 euros ; les intérêts capitalisés peuvent faire monter votre solde au‑dessus de 22 950 euros sans enfreindre le plafond. Attention : une personne ne peut détenir qu'un seul Livret A ; et le LEP peut offrir une meilleure rémunération pour les foyers éligibles. Vous souhaitez faire le point sur votre situation ? Prenez rendez-vous via le lien dans ma bio.

## Légende
Les livrets réglementés ont des plafonds sur les versements cumulés, pas sur le solde : les intérêts capitalisés peuvent porter le solde au‑dessus du plafond. Un seul Livret A par personne ; vérifiez votre éligibilité au LEP si vos revenus le permettent.
