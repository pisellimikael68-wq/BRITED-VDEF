# BRITED Social Video System — dossier Claude Design

## Objectif

Améliorer uniquement la direction artistique et les composants visuels des vidéos verticales BRITED, sans altérer le fond éditorial certifié.

## Source de vérité

- Les scripts certifiés de BRITED Studio gouvernent le texte, l’ordre narratif, les chiffres, les réserves, les exemples et les sources.
- Les chartes présentes dans `01_chartes_validees/` gouvernent le format de chaque plateforme.
- Les vidéos présentes dans `02_references_validees/` sont les seules références audiovisuelles autorisées.
- Les vidéos produites après le premier jour et non validées ne font pas partie de ce dossier et ne doivent jamais servir de modèle.

## Mission confiée à Claude Design

Proposer une amélioration visuelle cohérente, chaleureuse, professionnelle et mobile-first : composition, hiérarchie typographique, cadres adaptatifs, pictogrammes, micro-animations, transitions et variantes de CTA.

## Interdictions absolues

Claude Design ne doit jamais :

- réécrire, résumer ou compléter un script ;
- modifier un chiffre, une réserve juridique ou fiscale, une source ou l’ordre des idées ;
- inventer une nouvelle identité de marque visible ;
- ajouter « BRITED », un domaine, un nom d’application ou des libellés internes tels que Hook, Règle, Question ou Réponse ;
- utiliser une vidéo non validée comme référence ;
- produire ou déclencher une publication.

## Première demande recommandée

Créer trois pistes basse fidélité en 9:16 pour sept écrans types : accroche, question, réponse, explication, exemple, nuance/réserve et CTA. Conserver les règles verrouillées. Attendre la validation humaine d’une piste avant de travailler les animations ou la haute fidélité.
