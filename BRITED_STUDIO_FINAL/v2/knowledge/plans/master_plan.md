# BRITED Knowledge Master Plan

## Mission

Le Master Plan est le référentiel officiel de la Knowledge Base BRITED.

Il décrit :

- les piliers ;
- les familles ;
- les chapitres ;
- leur état d'avancement.

Aucune famille ne peut entrer en production sans disposer d'un fichier `*_plan.md` validé.

---

# Architecture officielle

```
Pilier
    ↓
Famille
    ↓
Chapitre
    ↓
Topic
```

Cette architecture est figée.

---

# Workflow officiel

Chaque famille suit obligatoirement les étapes suivantes :

1. Conception (`*_plan.md`)
2. Validation
3. Génération des Topic(...)
4. Audit qualité
5. Intégration dans la Knowledge Base

# Règles de production

Avant de produire des Topics :

- le plan de la famille doit être validé ;
- les chapitres doivent être figés ;
- les missions pédagogiques doivent être définies.

Une fois la production commencée, l'architecture de la famille ne doit plus être modifiée sans mise à jour préalable du fichier `*_plan.md`.
