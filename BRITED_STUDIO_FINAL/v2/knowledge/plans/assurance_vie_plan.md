# BRITED Knowledge Design

# Famille : Assurance-vie

## Mission

Construire une compréhension complète de l'assurance-vie en tant qu'enveloppe patrimoniale.

À l'issue de cette famille, un lecteur doit être capable de :

- comprendre le fonctionnement juridique d'une assurance-vie ;
- choisir un contrat adapté à ses objectifs ;
- comprendre les différents supports d'investissement ;
- maîtriser la fiscalité des rachats et du décès ;
- rédiger et comprendre une clause bénéficiaire ;
- utiliser l'assurance-vie dans une stratégie patrimoniale ;
- éviter les erreurs les plus fréquentes.

---

# Objectif global

L'ensemble de cette famille constitue la référence BRITED sur l'assurance-vie.

Elle doit permettre de générer :

- articles
- carrousels
- vidéos
- newsletters
- FAQ
- scripts
- formations

à partir des mêmes Topics.

---

# Volume cible

Environ 220 Topics.
