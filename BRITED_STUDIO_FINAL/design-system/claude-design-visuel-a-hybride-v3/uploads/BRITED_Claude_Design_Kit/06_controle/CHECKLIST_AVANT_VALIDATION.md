# Checklist avant validation humaine

## Fidélité éditoriale

- [ ] Aucun mot, chiffre, exemple, réserve ou source du script n’a été modifié.
- [ ] L’ordre narratif est inchangé.
- [ ] Aucun libellé interne ni marque visible n’a été ajouté.

## Composition

- [ ] Le titre et son cartouche sont correctement dimensionnés.
- [ ] Le texte est centré dans l’espace utile.
- [ ] Une seule idée cohérente figure sur chaque page.
- [ ] Tous les éléments respectent les zones sûres.
- [ ] Aucun texte, cadre ou pictogramme n’est coupé ou superposé.

## Mouvement

- [ ] Les mots apparaissent par fondu fluide, jamais avec un effet saccadé.
- [ ] La transition de page est définie à 0,9 seconde.
- [ ] Les pictogrammes apparaissent progressivement pendant la lecture.
- [ ] La barre de progression est uniquement en bas.

## Question et CTA

- [ ] La question précède la réponse.
- [ ] OUI/NON ne sont présents que dans leurs cases.
- [ ] La réponse suivante est complète, centrée et non répétée.
- [ ] Le CTA correspond exactement au mode pédagogique ou rendez-vous.
- [ ] La dernière page ne commence qu’après le contenu principal.

## Sorties attendues de Claude Design

- [ ] Maquettes 1080 × 1920.
- [ ] Composants et variantes exportables.
- [ ] SVG ou illustrations transparentes réutilisables localement.
- [ ] Paramètres d’animation documentés.
- [ ] Aucun fichier de production ou script source écrasé.
