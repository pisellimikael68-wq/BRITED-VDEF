# BRITED Studio — reconstruction locale

Cette installation fonctionne exclusivement depuis son dossier local. Elle ne
publie jamais automatiquement. Les scripts sont produits depuis les fiches du
dossier `content`, contrôlés, puis conservés dans `scripts`.

- Serveur : http://127.0.0.1:8766
- Deux créneaux quotidiens : 10 h et 17 h
- Plateformes : TikTok, Instagram Reels, YouTube Shorts
- Publication : toujours verrouillée jusqu'à validation humaine
